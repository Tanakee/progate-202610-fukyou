推し風（仮）図面一覧

全体

  • システム全体像FE、BE、ストレージ、風データのつながり
  • 風データが曲になるまでオープンデータから再生までの流れ
  • データモデルマイグレーションと同じテーブル定義

APIシーケンス

  • ログイン/auth/signup、/auth/login
  • 風船を飛ばす/tracks、/balloons
  • 風データ取得と位置配信3時間ごとの取得と、balloons.snapshot
  • 聴く、回数を数える最寄り判定、/balloons/:id/plays
  • 回収と割る/balloons/:id/collect、/balloons/:id/pop
  • 海や国外で旅が終わるballoon.removed、balloon.ended

状態遷移

  • 風船の状態遷移作成から記録カードまで
  • 再生の状態遷移流す設定、フェード、一時停止
