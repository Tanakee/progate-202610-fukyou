風船がないとき

  1. 風船を飛ばす API はまだないので、rails console から確認用の風船を作ります。 
    docker compose exec app ruby bin/rails runner '
u = User.find_or_create_by!(email: "viewer@example.com") { _1.password = "password123" }
t = Track.create!(user: u, title: "確認用", artist: "確認用", mp3_url: "https://example.com/a.mp3")
Balloon.create!(user: u, track: t, origin_label: "大阪市", origin_lat: 34.7, origin_lng: 135.5,
                lat: 34.7, lng: 135.5, moved_at: Time.current, launched_at: Time.current)'
  2. 速く動く様子を見たいときは、compose.yaml の SPEED_SCALE を大きくして docker compose up -d します。
  3. 片付けるときは次を実行します。 
    docker compose exec app ruby bin/rails runner '
u = User.find_by!(email: "viewer@example.com")
Balloon.where(user: u).delete_all; Track.where(user: u).delete_all; u.destroy!'
